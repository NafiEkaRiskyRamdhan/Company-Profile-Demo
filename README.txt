=== PANDUAN PENGGUNAAN & UPLOAD WEB PT NARANA SAMUDERA ABADI ===

1. STRUKTUR FILE:
   - index.php    : Halaman Utama website (Beranda, Profil, Visi Misi, Layanan, Struktur Organisasi, Kontak & Form Email)
   - style.css    : File desain tampilan (CSS) dengan tema profesional Navy & Gold maritim.

2. FITUR KIRIM EMAIL:
   - Form kontak di halaman bawah sudah terhubung dengan skrip PHP native.
   - Pesan yang dikirim pengunjung melalui form akan otomatis terkirim ke:
     naranasamuderaabadi@gmail.com
   - Catatan Hosting: Pastikan hosting Anda mengaktifkan fungsi mail() atau mendukung SMTP mail server agar email langsung masuk ke Inbox.

3. CARA UPLOAD KE HOSTING (cPanel / Hostinger / dll):
   - Login ke panel hosting Anda (cPanel/hPanel).
   - Masuk ke menu 'File Manager' -> folder 'public_html'.
   - Upload file 'index.php' dan 'style.css' ke dalam folder 'public_html'.
   - Website siap diakses melalui domain Anda!
